5. SERVER.JS
═══════════════════════════════════════════════════

Build server.js with:
- require express, express-session, and path (CommonJS — use require, not import)
- Create the express app
- Body parsing: express.json() and express.urlencoded({ extended: true })
- Serve /public statically with express.static(path.join(__dirname, 'public'))
- Session middleware configuration:
    - secret: process.env.SESSION_SECRET
    - If SESSION_SECRET is missing, console.error("FATAL: SESSION_SECRET is not set in Replit Secrets") and process.exit(1)
    - resave: false
    - saveUninitialized: false
    - cookie: { maxAge: 24 * 60 * 60 * 1000, httpOnly: true, secure: false }
- Record a SERVER_START_ISO constant on boot (new Date().toISOString())
- GET /api/health → returns 200 with { ok: true, startedAt: SERVER_START_ISO }
- Mount these routers (placeholders for now, but wire them up so the team can fill them in):
    app.use('/api/auth', require('./routes/auth'))
    app.use('/api/expenses', require('./routes/expenses'))
    app.use('/api/admin', require('./routes/admin'))
    app.use('/api/ai', require('./routes/ai'))
- Also expose GET /api/site/config that reads and returns data/site_config.json (this is a public read the frontend hits on every page load)
- Global error handler middleware: console.error the stack, return 500 with { error: "Something broke internally!" }
- Listen on process.env.PORT || 3000, log "🚀 Spendly running on port <port>"

Every HTML file uses this structure. Use Tailwind v4 via the browser CDN — not v3.

<!DOCTYPE html>
<html lang="en">
<head>

  <link rel="stylesheet" href="/css/style.css" />
</head>
<body class="bg-slate-50 text-slate-900 min-h-screen">

    <span id="tw-dot" class="inline-block w-2 h-2 rounded-full bg-emerald-500"></span>

    <span id="boot-time" class="text-slate-500">…</span>

    <span id="ping-result" class="text-slate-500">·</span>

  <main class="p-8 pt-16">
    <h1 class="text-3xl font-bold mb-2">Spendly — <PAGE_NAME></h1>
    <p class="text-slate-600">Placeholder page. <PAGE_NAME> UI will be built in later checkpoints.</p>
  </main>

  <script>
    // Dev banner logic — Tailwind verification + backend ping + boot time
    (async () => {
      try {
        const res = await fetch('/api/health');
        const data = await res.json();
        document.getElementById('boot-time').textContent = 'boot ' + new Date(data.startedAt).toLocaleTimeString();
      } catch (e) {
        document.getElementById('boot-time').textContent = 'boot ?';
      }
      document.getElementById('ping-btn').addEventListener('click', async () => {
        const el = document.getElementById('ping-result');
        el.textContent = '…';
        try {
          const r = await fetch('/api/health');
          el.textContent = r.ok ? '✅' : '❌';
        } catch {
          el.textContent = '❌';
        }
      });
    })();

</body>
</html>

For each of the 9 pages, replace <PAGE_NAME> and <PAGE_FILENAME>:
- index.html       → "Landing"            / "index.html"
- dashboard.html   → "Dashboard"          / "dashboard.html"
- expenses.html    → "Expense Log"        / "expenses.html"
- goals.html       → "Goals & Wishlist"   / "goals.html"
- coach.html       → "AI Coach"           / "coach.html"
- analytics.html   → "Analytics"          / "analytics.html"
- profile.html     → "Profile"            / "profile.html"
- admin.html       → "Admin"              / "admin.html"
- checkpoints.html → "Checkpoints"        / "checkpoints.html"

The dev banner in the top-right is critical — it lets us verify three things at a glance in the Replit preview:
  1. The green dot proves Tailwind v4 loaded (otherwise no styling, no green circle).
  2. The "boot <time>" proves the backend started and /api/health works.
  3. The "ping" button hitting it again proves the API stays reachable.
If any of those three fail, the preview is broken. Add a clear comment in each HTML file saying this banner should be removed before the final demo.

9. REPLIT SECRETS REQUIRED
═══════════════════════════════════════════════════

Before the server can start, two secrets must be set in Replit (the 🔒 icon in the sidebar):
- SESSION_SECRET — any long random string (the server will refuse to boot without this)
- GROQ_API_KEY — needed later for AI features, not for boot

After building, remind the user to set SESSION_SECRET in Replit Secrets or `npm start` will exit immediately.
